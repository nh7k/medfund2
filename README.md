✨ Overview

MedFund is a blockchain-powered hospital donation platform designed to help financially struggling patients receive transparent and secure medical funding.

The platform leverages Ethereum Smart Contracts, IPFS decentralized storage, and a modern React.js frontend to eliminate trust issues, reduce intermediaries, and provide complete transaction transparency.

Traditional fundraising platforms often face:

❌ Lack of transparency
❌ Delayed fund transfers
❌ High platform fees
❌ Fraud and trust concerns
❌ Centralized control over donations

MedFund solves these issues through decentralized infrastructure and immutable blockchain records.

🚀 Core Features
🔐 Blockchain Transparency

Every donation is securely recorded on the Ethereum blockchain for complete auditability.

🏥 Verified Hospital System

Only authenticated hospitals can create and manage patient fundraising campaigns.

🌍 Global Donation Network

Anyone around the world can contribute directly using crypto wallets.

📦 IPFS Decentralized Storage

Medical documents and campaign metadata are stored securely using IPFS.

💸 Secure Smart Contract Transactions

Funds are processed through immutable smart contracts without third-party intermediaries.

⚡ Lightning Fast Frontend

Modern React + Vite architecture ensures smooth user experience and fast rendering.

🔗 Web3 Wallet Integration

Seamless wallet connectivity using MetaMask and Ethereum providers.

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone https://github.com/nh7k/medfund2.git
cd medfund2
2️⃣ Install Dependencies
npm install
3️⃣ Start Frontend
npm run dev
4️⃣ Start Hardhat Node
npx hardhat node
5️⃣ Deploy Smart Contracts
npx hardhat run scripts/deploy.js --network localhost
